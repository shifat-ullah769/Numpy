# NumPy Practice & Learning 🚀

This repo contains all my practice files, notes, and codes from learning **NumPy (Numerical Python)**. 

I completed this learning journey by following the amazing NumPy playlist on the **CampusX** YouTube channel to build a strong foundation for Data Science and Machine Learning.

## 📚 Key Topics Covered
- **Array Basics:** Creation (1D, 2D, 3D), Indexing, Slicing, and Reshaping.
- **Operations:** Vectorized operations, Mathematical functions, and Broadcasting.
- **Data Manipulation:** Copy vs View, Sorting, Filtering, and Joining arrays.
- **Performance:** Understanding why NumPy is faster than Python Lists.

## 📁 Repository Structure
* `Basics/` - Introduction to arrays and indexing.
* `Advanced/` - Operations, broadcasting, and manipulation.
* `Exercises/` - Practice problems and solutions.

## 🛠️ How to Setup
1. Clone this repository:
   ```bash
   git clone https://github.com
   ```

